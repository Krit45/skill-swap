---

## ⚙️ Setup  

```bash
1. Update the 'firebase-applet-configuration' with your firebase applet configuration 
2. Install dependencies:
   `npm install`
3. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
4. Run the app:
   `npm run dev`
```
